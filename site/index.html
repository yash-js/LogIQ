What's inside

Practice that feels like a game,
and actually teaches.

Most people jump into DSA before they can turn a problem statement into code. LogIQ covers that missing step.

Phase 0 · Basecamp

New to the language? Start at Basecamp.

Ten short units per language: output, variables, strings, input, conditions, loops, arrays, functions and reading errors. Every exercise is written separately for Java, Python and JavaScript, not translated from one to the others.

  • Six exercise types: predict the output, fill the blanks, order the lines, fix the bug, write it yourself, pick one
  • Three lives per unit, combo XP for streaks of right answers
  • Already know the basics? Pass the 10-question placement test and skip ahead
Real runner

Your code runs on your machine, for real.

LogIQ compiles and runs your solution with the JDK, Python or Node already on your PC. Run checks the examples. Submit runs the hidden tests as well, with time limits and clear errors.

  • Java, Python and JavaScript, with a starter for each problem
  • Reading input and printing are handled for you, so you only write the logic
  • Three hints per problem, each one costs a little XP
Pure challenge

Used sort()? Now try it without.

Library shortcuts like sort, Set, max() or reverse() do the thinking for you. A correct answer still counts, but LogIQ spots the shortcut and opens a Pure challenge: solve it again with only loops, conditions, arrays and strings for +50% XP.

  • The editor shows which shortcuts it spotted while you type
  • Pure solves are tracked separately on your profile
Progress

XP, levels, streaks. And your data is yours.

Daily quests give double XP, streaks keep you coming back, and badges mark milestones. Everything is saved in a local SQLite file. There's no server and no account.

  • Export or import your progress as a JSON file
  • Automatic daily backups, the last 14 kept
  • Each world has a short guide and a quiz before its problems open

FAQ

Questions.

Is this DSA practice?

No, it comes before DSA. LogIQ trains turning a problem into code using conditions, loops, recursion, arrays and strings. Once that is easy, data structures and algorithms go much faster.

Is it really free? Do I need an account?

Yes, it's free and open source. There's no login, no server and no tracking. The app runs completely offline after you download it.

Windows says "Windows protected your PC". Is it safe?

The installer isn't code-signed yet, so SmartScreen warns about any new app. Click More info, then Run anyway. The full source is on GitHub, and the installers are built there by GitHub Actions.

Where is my progress stored?

In a SQLite file in your user's app-data folder, with a daily backup next to it. You can export everything to a JSON file from Settings and import it on another computer.

Can I switch languages midway?

Yes. Switch anytime from the sidebar. Guides, quizzes, hints and starters all change to that language, and a problem you solve in more than one language shows each one.

Why a desktop app and not a website?

Running Java, Python and Node on your own machine is fast, free and works offline. It's also the same setup you'll use for real projects.
